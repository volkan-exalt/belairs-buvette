# Documentation Guidelines

Ces consignes s'appliquent lors de la redaction ou modification de documentation.

## Langue et ton

- Pour les fichiers francais (`*_fr.md`), rediger en francais clair.
- Garder un ton pedagogique, direct et utile.
- Eviter les formulations trop longues ou ambigues.

## Markdown

- Utiliser des titres courts.
- Preferer des listes simples quand elles ameliorent la lecture.
- Garder les chemins et commandes entre backticks.
- Verifier que les liens relatifs pointent vers des fichiers existants.

## Contenu projet

- `README_fr.md` doit rester centre sur l'installation, la structure et le demarrage.
- `FEATURES_fr.md` doit rester centre sur les user stories et regles metier.
- Les consignes agents doivent rester dans `docs/agents/instructions/`.

## Maintenance

- Mettre a jour la documentation quand un changement modifie une commande, une structure de dossier ou une convention importante.
- Ne pas documenter une fonctionnalite comme terminee si elle n'est pas implementee ou testee.
